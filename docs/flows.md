# โฟลว์การใช้งาน

## 6 ปุ่มเมนู

| ปุ่ม | ทำงาน |
|---|---|
| ต้องการโพสต์ | โชว์ draft ปัจจุบัน (รูป/วิดีโอ/ข้อความ) |
| แก้ไขรูป | ล้างรูป+วิดีโอเก่าทั้ง state และไฟล์ รอรับของใหม่ |
| แก้ไขข้อความ | ล้างเฉพาะข้อความ รูปยังอยู่ |
| เลือกเพจ | สลับไปหน้าเลือกเพจ (แตะปุ่มใหญ่ / Quick Reply / พิมพ์ชื่อเพจ/เลข ได้หมด) |
| โพสต์ใหม่ | ล้างทั้งหมด เริ่ม draft ใหม่ |
| โพสต์ | มี draft + เลือกเพจแล้ว = โพสต์ทันที / ยังไม่เลือกเพจ = ถามเพจแล้วโพสต์อัตโนมัติ |

## เลือกเพจ (ทุกทางเข้าที่เดียวกัน)
แตะปุ่ม Quick Reply · แตะปุ่มหน้าเมนู (ส่ง `1`/`2`) · พิมพ์ `1`/`2` · พิมพ์ชื่อเพจ
(`ก๊อดเองแม่ตั้งให้`/`ก๊อดเอง`/`GETUP DEAL`/`getupdeal`/`getup`) — exact match เท่านั้น
แคปชันที่มีชื่อเพจปนอยู่ยังเป็นแคปชันปกติ

## ส่งคอนเทนต์
- ส่งรูปได้หลายรูป (รวมเป็นอัลบั้มเดียว) / วิดีโอได้ครั้งละ 1 ไฟล์ (~200MB)
- ส่งแคปชัน → ได้ Preview → กดปุ่ม `โพสต์`
- ตั้งเวลา: พิมพ์เวลาในแคปชัน เช่น `โพสต์ 19:45`, `พรุ่งนี้ 09:00` (ล่วงหน้า ≥10 นาที)

## คำสั่งพิมพ์เพิ่มเติม
`ใช่`/`ยืนยัน`/`ตกลง` (= ปุ่มโพสต์) · `โพสต์ใหม่`/`เริ่มใหม่` · `เลือกเพจ`/`เปลี่ยนเพจ` ·
`สร้างรูป` (AI) · `2` ตอน draft ว่าง = สร้างรูป AI
